## ⭐ [精选项目](https://github.com/Jia0612/Jia0612/tree/main#-featured-projects)

让新手做工程更顺手的工具。

🗺️ [understand-everything-for-beginners](https://github.com/Jia0612/understand-everything-for-beginners)：把任何项目变成一张可交互的大白话导览图，帮技术过硬的工程师讲清楚自己做了什么、为什么这么设计、做了哪些权衡——哪怕不懂技术的相关方也能一听就明白。

🔤 [code-translation](https://github.com/Jia0612/code-translation)：把代码库的核心文件变成一本可交互的书，用大白话逐行讲解每一行代码。

🧩 [leetcode-to-course](https://github.com/Jia0612/leetcode-to-course)：把一道力扣题变成零基础也能学的交互课程——从手动推演，到理解更快的解法。

▶️ [youtube-to-course](https://github.com/Jia0612/youtube-to-course)：把一节 YouTube 课程变成交互课，字幕经过核验、代码对照过出处，还配有测验和大白话讲解。

📝 [blog-to-course](https://github.com/Jia0612/blog-to-course)：把任何长文变成交互课程，原文的观点、引用和出处原汁原味保留。

📖 [pdfbook-to-course](https://github.com/Jia0612/pdfbook-to-course)：把 PDF 书籍的一个章节变成交互课程，配可视化讲解和一个有据可依的设计跟练练习。
